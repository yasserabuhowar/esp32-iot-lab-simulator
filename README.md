# مختبر ESP32: نظام مراقبة الحرارة والرطوبة

محاكاة تعليمية ثلاثية الأبعاد لمشروع ESP32 + DHT22 + LCD I2C + Buzzer، مع إرسال القراءات إلى ThingsBoard عبر MQTT.

**افتح المحاكي:** https://yasserabuhowar.github.io/ESP32-stimulator-/

## المحتوى
- طاولة عمل ثلاثية الأبعاد بالتوصيل الحقيقي: DHT22 على GPIO15، وLCD على 21/22، وBuzzer على 18، وزر محاكاة انقطاع WiFi على 4.
- جولة إرشادية من 8 خطوات، فيها مقتطفات من الكود.
- 4 حالات اختبار: حرارة طبيعية، حرارة مرتفعة، انقطاع WiFi، قراءة غير صالحة.
- لوحة ThingsBoard محاكاة، وSerial Monitor.

## منطق المحاكاة (مطابق لـ sketch.ino)
- قراءة كل ثانيتين، وإرسال كل 5 ثوانٍ.
- الإنذار يعمل فوق 35°C ويتوقف عند 34°C أو أقل (Hysteresis).
- مخزن مؤقت دائري يتسع لـ 60 عينة أثناء الانقطاع، تُرسل بتوقيتها الأصلي عند عودة الاتصال.
- رفض القراءات غير الصالحة، وبعد 3 قراءات خاطئة متتالية تظهر SENSOR ERROR.

## الملفات
- `index.html`: النسخة المنشورة (تحتاج إنترنت لتحميل Three.js).
- `ESP32_Lab_offline.html`: نسخة كاملة تعمل بدون إنترنت، للتحميل والإرسال.

> محاكاة تعليمية، لا تغني عن تشغيل الكود الحقيقي في Wokwi وربطه بـ ThingsBoard.
